A study site for my 12-week calculus course. It covers Calculus 1 to 3 in one place, so I can learn each topic, test myself, and ask questions.

  • A quiz for every lesson
  • Animated video lessons
  • Q&A forum with voting
  • CalcBot, a study helper chat
  • Optional accounts, no email

Built with Python, Flask, SQLite, HTML, CSS and JavaScript.
